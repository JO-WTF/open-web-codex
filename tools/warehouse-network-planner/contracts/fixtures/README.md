# Final delivery fixtures

The complete Indonesia map and typed report-source payloads are provider-owned
test fixtures. They are generated from `NetworkComparisonMapBundle` and
`NetworkPlanningReportBundle` by the `sample2_delivery` fixture in
`tests/test_delivery_bundles.py`; the corresponding versioned JSON Schemas in
`contracts/schemas/` are generated by `scripts/generate_delivery_schemas.py`.

The user-facing report is not that JSON source payload. The provider deterministically
renders `network_planning_report_markdown.v1.md` from the validated report source; the
Platform validates and serves the exact Markdown bytes for reading and download.

The Platform consumes these files only as validation fixtures. It does not
interpret warehouse fields or define a second domain contract.

`warehouse_quote_mean_calculation.v1.json` is the bounded script-evidence fixture.
Its input identity is synthetic; production evidence is accepted only when the
Planner re-derives the same total count, per-layer counts, currency, formula and
means from the exact prepared Workspace input.
