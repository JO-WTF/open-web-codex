# 评估财务方案

1. 只比较同一个 Network Case 中、使用相同需求版本、路线方法、服务策略、币种和期间的基线与候选方案。
2. 向用户确认评估年限、折现率、需求增长和一次性投入。探索性默认值必须显式标注，不能隐藏。
3. 使用确定性财务工具计算，不在模型回复中重新实现公式。
4. 输出币种、期间、假设、排除项、净现值、回收期和敏感性边界。

正的模型净现值不等于投资授权。输入不兼容或关键参数缺失时必须停止并请求用户确认。
