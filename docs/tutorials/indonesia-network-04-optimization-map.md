# 找出达到 90% 的最少新增仓

当你不想先指定具体新增地点，而是想知道“为了达到目标，最少还要开几个仓”，使用这一问。

## 直接这样问

```text
计算时效达标率为 90% 的前提下最少的新增仓库数量和选址结果，并用地图可视化。
```

如果不说明时效，系统会向你确认目标时限。想同时控制成本时可以补充：

```text
在达到 90% 目标的方案中，使用已有报价选择总成本最低的组合。
```

## 默认规则

- 现有仓库默认保留；
- 只从你上传的候选仓中选择新增地点；
- 先找达到目标所需的最少新增数量；
- 在新增数量相同的可行方案中，再比较成本。

如果你允许关闭现有仓，请明确写出哪些仓可以关闭。系统不会仅凭“越库仓”这一名称自动关闭它。

## 成功结果应包含

| 结果 | 你需要检查什么 |
| --- | --- |
| 新增仓数量 | 是否是达到目标所需的最少数量，还是仅为当前可行方案 |
| 选址列表 | 每个选中的候选仓名称和位置 |
| 最终达标率 | 是否达到你提出的目标 |
| 地图 | 新增仓、现有仓、达标/未达标城市和服务线路 |

当系统在给定时间内证明“再少一个仓就无法达到目标”时，才会说“最少”。如果只找到了一个可行方案但没有完成证明，会明确说明这一点。

## 可能出现的正常结果

- **可以达到目标**：给出最少新增仓和地图；
- **在当前候选中无法达到目标**：说明差距和需要扩大什么条件；
- **缺少路线或报价**：请你补充或确认规则后再继续；
- **计算未完成**：保留已经确认的事实，不把临时结果说成最优方案。
