# 评估新增 Balikpapan 仓

这一页教你比较一个明确的新增仓方案，而不是让系统自行挑选所有仓。

## 直接这样问

在完成 12 小时基准分析的同一个任务中，发送：

```text
评估添加仓库 Balikpapan 之后对时效达标率的影响，并绘制对比地图。
```

如果还想比较成本，可以补一句：

```text
同时按我上传的报价比较总成本，并说明缺少报价的部分。
```

## 你会得到什么

结果应清楚比较“新增前”和“新增后”：

- 12 小时需求量加权达标率各是多少；
- 变化了多少个百分点；
- 哪些城市的服务关系发生变化；
- 成本数据完整时，总成本如何变化；
- 一张区分前后方案的地图。

“提升 5 个百分点”表示例如从 81% 到 86%，不是在原数字上增加 5%。

## 如果出现输入卡片

这通常表示缺少一个必须由业务决定的条件，例如路线估算方式、报价规则或仓库类型。选择最符合业务的选项；示例练习可以选择第一个默认项。

系统在等待你的选择时，不会继续计算或画一张假地图。回答后原任务会接着完成。

## 怎样避免误读

- 某城市被分给 Balikpapan，说明新方案把它交给该仓服务；
- 这本身不能证明 Balikpapan 对它一定更快或更便宜；
- 若要知道具体原因，请追问“比较该城市由两个仓服务的时效和成本”；
- 某城市即使仍未达标，也会被分配给一个启用仓，以便统计成本和服务关系。

新增仓的效果只对当前上传的候选地点、路线、报价和时效目标负责。更换其中任何一项后，应重新计算。
