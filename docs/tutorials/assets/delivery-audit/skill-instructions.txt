Call delivery_audit.audit_delivery_commitments exactly once with the platform-authorized
Workspace ID, Dataset Release ID, Dataset ID, version, and content SHA-256 injected into
the Agent instructions. Use only the Tool result for counts, rates, late shipment IDs,

been authorized for the required data. In the final answer, state the shipment on-time
rate, demand-weighted on-time rate, worst province, late shipment IDs, exact Dataset

Tool. Do not expose the internal data_ref URI.
